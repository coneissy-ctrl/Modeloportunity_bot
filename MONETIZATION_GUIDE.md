## ✅ Deployment Steps

1. **Run the bot:**
   ```bash
   docker-compose up
   ```

2. **Test both flows:**
   - Say "I want to join" → See model signup buttons
   - Say "How do I earn?" → See affiliate button

3. **Deploy to production:**
   - Push to Vercel (frontend)
   - Push to Railway/Render (backend)

4. **Start marketing:**
   - Share bot link on social media
   - Recruit both models and affiliates
   - Track conversions
